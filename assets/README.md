# Assets

Both images here were generated by this server, which is the point: it is the
cheapest honest demo of what the tool does. Recorded so they can be regenerated
or restyled later.

## hero.jpg

README banner. `gemini-3.1-flash-image`, `aspect_ratio: 16:9`, `image_size: 2K`.
Downscaled to 1920px wide and recompressed at quality 82, because the raw 2752px
output was 1.7 MB and a README should not ship that.

> A clean, modern hero banner for a developer tool. Dark charcoal background with
> a subtle grid. On the left, a stylized terminal window in flat vector style
> showing abstract lines of code as colored bars, no readable text. Flowing out of
> the terminal toward the right, a smooth gradient ribbon of light that resolves
> into three overlapping image thumbnails with rounded corners: a lighthouse at
> dusk, a flat paper airplane icon, and an abstract logo mark. Soft teal, violet,
> and warm amber accents. Generous negative space, balanced composition, crisp
> geometric shapes, subtle depth, no text anywhere, no letters, no words.

## social-preview.jpg

GitHub social preview, set under Settings, Social preview. Exactly 1280x640, well
under the 1 MB limit.

Generated at 16:9, then center-cropped to 2:1 and resized. The prompt asks for
wide empty margins at the top and bottom specifically so that crop does not eat
the composition, since the tool offers 16:9 and 21:9 but not 2:1.

> A GitHub social preview card for a developer tool. Dark charcoal background with
> a subtle fine grid. Composition strictly centered with wide empty margins at the
> top and bottom so it survives a crop to a 2:1 banner. In the center, large clean
> sans-serif lowercase text reading exactly "image-gen-mcp" in crisp white,
> perfectly spelled, with below it in smaller muted grey lowercase text reading
> exactly "generate and edit images from your coding agent". To the left of the
> text, a compact flat vector terminal window icon emitting a smooth teal-to-violet
> gradient ribbon that resolves into two small rounded image thumbnails. Soft teal,
> violet, and warm amber accents. Minimal, high contrast, professional, geometric,
> plenty of negative space.

## Regenerating

Ask an agent with this server configured, or use the smoke CLI. Post-processing
was done with `sips`, which ships with macOS:

```bash
# Social preview: center-crop 16:9 to 2:1, then down to GitHub's 1280x640.
sips -c 1376 2752 social.jpg
sips -z 640 1280 social.jpg
sips -s format jpeg -s formatOptions 80 social.jpg --out social-preview.jpg

# Hero: down to 1920 wide.
sips -Z 1920 hero.jpg
sips -s format jpeg -s formatOptions 82 hero.jpg --out hero.jpg
```

Both prompts deliberately specify "no text" (hero) or the exact strings to render
(social card). Image models are unreliable with incidental text, so either forbid
it or state it verbatim and check the result.
